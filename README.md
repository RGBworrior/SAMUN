# SAMUN Website

A premium deep-purple + gold single-page SAMUN conference website.

## Open in VS Code

1. Extract this folder.
2. Open the `SAMUN` folder in VS Code.
3. Open `index.html`.
4. Recommended: install the VS Code extension **Live Server**.
5. Right-click `index.html` → **Open with Live Server**.

## Before publishing

Replace:
- Conference date in `script.js`
- Registration URL in `index.html`
- School/contact details
- Committee names/descriptions
- Schedule
- Social media links

The current registration link is a Google Forms placeholder.
